## ⚔️ What is THRYLOS?

**THRYLOS INDIA** is a purpose-built, production-grade **internal admin management portal** for operating a full-scale esports and digital operations platform in India. Every single module in this portal is **manually administered** — there is no public self-service. Admins manage everything: tournaments, team attendance, HR records, payroll documents, intern tracking, payments, certificates, audit logs, and real-time team communications — all from a single authenticated command center.



This is not a template. This is a **live, operational platform** running India's esports administration stack.



> ⚠️ **Skill-Games Only** — THRYLOS operates exclusively with **skill-based competitive games**. No gambling, no betting, no chance-based mechanics. Fully compliant with Indian gaming law and MSME regulations.

## 🔐 Authentication System

The admin portal uses a **zero-password, OTP-based authentication pipeline** — no stored passwords, no shared credentials. Every login is verified via a one-time code sent to the admin's registered email through Supabase Edge Functions and the Brevo transactional API.

### Login Flow

```
Admin opens admin.thrylos.in
            │
            ▼
┌───────────────────────────┐
│  1. Email Input           │
│  Enter registered email   │
└───────────┬───────────────┘
            │
            ▼
┌─────────────────────────────┐
│  2. Location Capture        │
│  Browser Geolocation API    │
│  → Lat, Long, City, IP      │
│    stored per login session │
└───────────┬─────────────────┘
            │
            ▼
┌─────────────────────────────┐
│  3. OTP Dispatch            │
│  Supabase Edge Function     │
│  calls Brevo REST API       │
│  → 6-digit OTP via email    │
│  → Expires in 5 minutes     │
└───────────┬─────────────────┘
            │
            ▼
┌─────────────────────────────┐
│  4. OTP Verification        │
│  Single-use, server-side    │
│  Validated by Edge Function │
└───────────┬─────────────────┘
            │
            ▼
┌─────────────────────────────┐
│  5. Session Established     │
│  Role assigned from DB      │
│  Supabase JWT issued        │
│  Admin lands on Dashboard   │
└─────────────────────────────┘
```

### Auth Architecture

| Component | Technology |
|---|---|
| **OTP Generation** | Supabase Edge Function (Deno runtime) |
| **OTP Delivery** | Brevo Transactional Email API |
| **Location Capture** | Browser Geolocation API → stored per session for audit |
| **Session Management** | Supabase Auth (JWT-based secure sessions) |
| **Role Enforcement** | Row-Level Security (RLS) on all Supabase tables |
| **Access Roles** | Super Admin · HR Admin · All Users · Module-specific |



> **No password is ever stored or required.** Every login is verified by a time-limited OTP delivered to the admin's email.

## 📧 Email Infrastructure

All outbound email is powered by **Brevo API** invoked through **Supabase Edge Functions** — server-side, quota-enforced, and fully logged.

### Admin Email Quota System

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   Each Admin Account                                    │
│   ├─ Daily Limit  : 15 emails / day                     │
│   ├─ Sender       : @admin.thrylos.in                   │
│   ├─ Engine       : Brevo Transactional REST API        │
│   ├─ Trigger      : Supabase Edge Function              │
│   ├─ Tracking     : Open rate, delivery, send count     │
│   └─ Reset        : Midnight IST daily                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Email Flow

```
Admin composes email in portal
             │
             ▼
   Supabase Edge Function called
   → Checks admin's daily quota
             │
      ┌──────┴──────┐
      │             │
  Under 15       At/Over 15
  emails             │
      │         ❌ Blocked
      ▼         Notify admin
  Brevo REST API called
      │
      ▼
  Email delivered to recipient
      │
      ▼
  DB log updated
  (send count incremented for today)
```

### Email Types

| Type | Trigger | Volume |
|---|---|---|
| **OTP Login Email** | Every admin login attempt | Per-login |
| **Certificate Issuance** | Certificate Manager module | On-demand |
| **Payment Receipts** | Payment verification approval | Per transaction |
| **Admin Composed Emails** | Email Management module | Max 15/admin/day |
| **Notifications** | System-triggered alerts | Automated |
