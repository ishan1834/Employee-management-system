04 · Data Flow
Realtime & Async Flows

How data moves: which pages subscribe to which channels, how mutations trigger side effects, how auto-attendance fires, and how notifications propagate.

Client Triggers
📝 Submit work log
tech_work_logs INSERT
→ useAutoAttendance fires
→ attendance INSERT/UPDATE
🔐 Admin login
signInWithPassword or verifyOtp
→ fetchLocationData (ipwho.is)
→ audit_logs INSERT
→ admin_activity_logs INSERT
→ admins.last_login UPDATE
💬 Send chat message
chat_messages INSERT
→ Realtime broadcasts to all
subscribed clients instantly
✅ Verify payment
payment_verifications UPDATE
→ postgres_changes fires
→ NotificationBell updates
→ Analytics re-fetches
🏆 Issue certificate
certificates INSERT
→ Realtime channel fires
→ NotificationCenter updates
📊 Any admin action
useActivityLogger.logActivity()
→ admin_activity_logs INSERT
→ ActivitySummary re-renders
⇄
Supabase Channels
⚡ analytics-realtime
Tables: esports_players
social_media_orders
payment_verifications
→ re-fetches all analytics on any change
⚡ payment-changes
Table: payment_verifications
event: * (INSERT/UPDATE/DELETE)
→ PaymentVerification page live update
⚡ payment-notifications
Table: payment_verifications
→ NotificationCenter bell badge
⚡ certificate-notifications
Table: certificates
→ NotificationCenter bell badge
⚡ internship-notifications
Table: internships
→ NotificationCenter bell badge
⚡ team-chat channel
Table: chat_messages
WebSocket broadcast
→ all connected admins receive instantly
⏱ Polling (non-realtime)
KanbanBoard polls kanban_tasks every 5 seconds via setInterval — not a Realtime subscription.
Dashboard fetches stats on mount and manual refresh only — no auto-polling.
